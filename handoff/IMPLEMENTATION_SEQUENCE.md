**Engineering Foundation (completada) → M1 Connected Decision Proof → MVP → Founding Pilot → Validation Evidence.** Orden técnico interno: Phase 1 Auth/Workspace/Brand → Phase 2 Context/DecisionVersion → Phase 3 Customer → Phase 4 Positioning → Phase 5 Change Impact/Guided Review → Phase 6 Blueprint → Phase 7 Capability → Phase 8 módulos restantes → Phase 9 Experiment/Signal/Learning → Phase 10 Pilot Instrumentation → Phase 11 hardening/evals/demo. Validar hipótesis durante construcción cuando sea útil; el viejo plan IEBS 90 días no es prerrequisito de M1.

**M1 criterio exacto:** (1) crear Brand; (2) Customer Decision; (3) Positioning Decision; (4) dependencia Positioning→Customer; (5) cambiar Customer; (6) conservar versión vieja; (7) nueva vigente; (8) Positioning Needs Review; (9) explicación; (10) humano revisa; (11) estado persiste. Gates técnicos: auth/tenant, human-only commit, optimistic version, idempotency, transacción/auditoría, determinismo rules-first, fallback sin research e integración/E2E.
