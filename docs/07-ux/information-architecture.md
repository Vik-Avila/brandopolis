# Arquitectura de información

Workspace Home → Brands → Brand Home → Strategy Journey (nueve módulos) → Strategic Question → Decision Card → Decision Detail/History → Change Impact/Guided Review. Accesos de Brand: Context, Blueprint, Experiments, Learning; de User: Strategic Practice/Capability; de Workspace: members/settings. Home prioriza preguntas abiertas, Needs Review, experimento activo, nuevo Learning y siguiente acción, sin vanity metrics. Blueprint es vista derivada, no editor maestro. Chat P1 puede proponer preguntas candidatas, nunca modificar contexto.
