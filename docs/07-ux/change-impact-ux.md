# Experiencia Change Impact

Tras commit upstream mostrar resumen de versión vieja/nueva y bandera «X decisiones requieren revisión». Por cada fila: Decision downstream vigente, relación y razón, severidad HARD/SOFT, evidencia/hypothesis afectada y CTA Review in Order. HARD muestra Needs Review sin esconder elección vigente. Revisión humana: mantener con explicación, aprobar nueva versión o invalidar explícitamente; actualizar ReviewItem con actor/fecha. Si motor falla: estado Impact Pending visible y cola reintentable, jamás «todo coherente». Semántica IA puede añadir contexto, no suprimir ítems deterministas.
