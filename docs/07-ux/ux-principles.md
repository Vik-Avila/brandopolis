# Principios UX

Strategic Workspace desktop first, sin chat dominante. Izquierda Journey; centro Decision Workspace; derecha Brand Context relevante. Progressive disclosure: pregunta y opciones primero, detalle de Evidence/trade-offs cuando se necesita. Siempre diferenciar propuesta IA de decisión humana, estado vigente de historial y suposición de fuente. Primer uso «What are you building?»; retorno «What changed?»; Home responde «¿Qué necesita mi atención?». Accesibilidad: teclado, foco visible, labels, mensajes de error accionables, contraste suficiente y avisos persistentes de Needs Review. La práctica estratégica acompaña, sin entorpecer a profesionales.
