# Jornadas de producto

**Primer uso:** signup → Workspace → Brand → progressive intake → primera Question → Evidence/Hypotheses → Options → Recommendation/Support → decisión humana → Context y siguiente pregunta; registrar TTF. **Recurrente:** entrar → What changed? → indicar cambio → comparar versiones → Impact → revisión en orden → Blueprint actual. **Aprendizaje:** registrar Experiment → Signal → revisar Learning → nueva Question. **Agencia:** misma cuenta en varias Brands, cada contexto aislado; segunda Brand es métrica de validación. **Falla IA:** continuar entrada y decisión manual, declarar que no hubo recomendación. Todas las jornadas necesitan vacíos, conflictos y permisos en `states-and-empty-states.md`.
