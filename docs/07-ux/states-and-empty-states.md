# Estados y vacíos

| Caso | Mensaje/acción segura |
|---|---|
| Brand vacía | What are you building? / crear contexto |
| Sin Evidence | distinguir hipótesis; continuar con soporte Unvalidated |
| IA no disponible o schema inválido | explicar fallo; entrada/decisión manual |
| Research no disponible | usar contexto aportado; sin fuentes inventadas |
| Contradicción | mostrar opciones en conflicto, permitir criterio humano |
| Recommendation stale | generar de nuevo o revisión humana explícita |
| Concurrencia | mostrar versión actual, comparar antes de nuevo commit |
| Acceso denegado | sin revelar existencia o datos de Brand |
| Dependency recalculation failed | Impact Pending visible, reintentar idempotente |
| Needs Review | elección anterior visible y advertencia persistente |
| Experimento sin Signals | pedir primera observación, no concluir Learning |
