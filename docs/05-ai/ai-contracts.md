# Contratos AI

Funciones especializadas, no swarm: Gateway → Assembler → Research opcional → Strategic/Activation Analysis → Evidence Guard → Evaluator → Recommendation. Decision Engine y Change Impact pertenecen al dominio y son reglas/commit humano, no LLM. `Recommendation` requiere options, rationale resumido, references, hypotheses, tradeoffs, openQuestions, supportLevel y affectedDomains; `failureConditions` opcionales. Prompt v1 usa Global + Function + Module + Packet + Output Schema. El LLM jamás accede a `commitDecision`, ni registra chain-of-thought privado. Output validado y fuentes de Brand comprobadas.
