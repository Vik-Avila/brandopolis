# Nueve módulos aprobados

| Módulo | Pregunta principal aprobada | Decisión principal |
|---|---|---|
| Understand | ¿Qué estamos intentando construir o cambiar? | Strategic Objective |
| Market | ¿En qué arena debemos competir inicialmente? | Market Arena |
| Customer | ¿Quién debe ser nuestro cliente prioritario? | Primary Customer |
| Business | ¿Cómo creamos y capturamos valor para ese cliente? | Value Mechanism |
| Position | ¿Qué posición estratégica queremos ocupar frente a las alternativas? | Positioning |
| Brand | ¿Qué debe significar nuestra marca para ese cliente? | Brand Promise |
| Message | ¿Qué idea principal queremos que comprenda y recuerde el cliente? | Core Message |
| GTM | ¿Dónde y cómo debemos concentrar inicialmente nuestros recursos? | GTM Priority |
| Experiment & Learn | ¿Qué supuesto crítico debemos validar primero? | Priority Experiment |

Todos existen en arquitectura P0; profundidad inicial máxima Customer → Business → Position → Message. Experiment & Learn cierra el ciclo mediante Signals y Learning revisados. Módulos restantes deben tener pregunta/decisión primaria; no forzar igual profundidad de interfaz en M1.
