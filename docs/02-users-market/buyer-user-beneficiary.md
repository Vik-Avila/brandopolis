# Buyer / User / Beneficiary

| Cohorte | Buyer | User | Beneficiario | Valor dominante |
|---|---|---|---|---|
| A, beachhead comercial | responsable de agencia/consultoría pequeña | consultor o profesional multibrand | equipo y clientes de marcas | método reutilizable, continuidad, segunda Brand |
| B, beachhead de impacto | founder/propietario PYME | founder u operador estratégico | negocio y equipo | recorrido guiado y mejores condiciones de decisión |

Buyer/User pueden coincidir, pero medir por rol real. Una agencia administra marcas separadas: acceso a Brand se autoriza explícitamente; no aprovechar datos de cliente A para otro. Mismo producto, no dos roadmaps.
