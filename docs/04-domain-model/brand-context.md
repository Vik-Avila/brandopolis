# Brand Context

Estado estructurado vivo de una Brand: Strategic Question, User Input, Evidence, Inference, Hypothesis, Recommendation, Decision, Dependency, Open Question, Experiment, Signal y Learning; distinguir Current State de History. No mega documento, chat ni Blueprint. Decision actual apunta a DecisionVersion inmutable; Evidence/Hypothesis/Dependency son consultables. `ASSUMPTION_IN_USE` es una condición/flag/relación adicional: una Decision vigente depende actualmente de una Hypothesis no validada. Nunca es un status de Hypothesis; los únicos estados son UNTESTED, TESTING, SUPPORTED, WEAKENED y REJECTED. Capability Context es personal User y está separado. Modelos canónicos específicos en [Decision](decision-model.md), [Evidence](evidence-model.md), [Hypothesis](hypothesis-model.md), [Graph](strategy-graph.md), [Learning](experiment-signal-learning.md).
