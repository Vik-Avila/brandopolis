# Definition of Done

Foundation: fuente, términos, schemas/examples, configs/prompts/evals, links, QA y handoffs coherentes; cotejo del Final Contract Patch independiente sigue pendiente. M1: veinte criterios en `docs/15-handoff/m1-acceptance.md`, invariantes y tests intertenant/stale/idempotency, audit, Human Commit. Función IA: input/output schema, prompt version, guard, fallos, telemetría y eval. MVP: flujo completo del Master sin dependencia del fundador. Pilot-ready: datos reales, consentimiento, intervenciones y fórmulas fijas. Demo: datos DEMO separados y guion reproducible. No considerar Done una especificación como si fuese feature implementada.
