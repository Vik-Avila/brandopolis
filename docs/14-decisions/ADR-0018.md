# ADR-0018 · Human review of Brando suggestions

Accept and Modify open the existing human decision editor. They never directly apply model
text as a selected option. The person specifies the actual choice, records the criterion and
confirms a new version through Engine.commitDecision. Existing readiness, concurrency,
review receipts, idempotency, history and Change Impact gates remain in force. Related
decisions can require review; their active versions are never automatically rewritten.

Reject requires a human reason and persists a practice observation without changing strategy.
Accept/Modify record practice only in the successful strategic commit, exactly once alongside
that version. All choices record practice, not a quality score or model-training signal.
Capability Context belongs to the authenticated User; the Brand audit records provenance.
No strategic Learning is automatically created or accepted.

Reuse existing capability_events, audit, telemetry and idempotency tables; no migration or
new schema table. Generated suggestions have opaque, actor/workspace/brand-bound proof in
a bounded process cache (512 entries, 15 minutes). Conversations are not persisted. Only the
suggestion explicitly reviewed by the human, their final choice and reason are durably stored.
A restart or expired/evicted proof requires a fresh query, except exact successful commit
replays served by existing durable idempotency. Rejected proof cannot later be applied.

Applying checks the original decision/context version; intentional question preparation is
allowed, but changed decisions/evidence/context make the proposal stale. Reject checks the
full Brando fingerprint. Source references are not proof of semantic correctness.

Prompt v2 uses concise everyday es-MX and translates internal codes; v1 remains retained.
The defensive text projection escapes generated content and translates known codes without
altering canonical sources or IDs. Original compact gemstone poses return via short fades;
no geometry morph, scaling or new imagery.

Release remains outside production; Jury Production Freeze unchanged. New Windows gates
and human review are required. No commit, push, merge, tag or deploy authorized here.
