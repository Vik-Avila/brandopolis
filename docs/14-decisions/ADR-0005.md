# ADR-0005: Model Gateway

- Contexto: fundación del sistema de decisiones de Brandopolis; contrato conceptual consolidado y aprobado en Master Context v1.0.
- Opciones: SDK acoplado / abstracción.
- Decisión propuesta: puerto interno y adaptador de proveedor inicial por definir.
- Consecuencias: telemetría y reversibilidad sin segundo proveedor P0.
- Revisión: coste/latencia/capacidad obligan cambio.

## Distinción obligatoria
Arquitectura Model Gateway ACCEPTED; proveedor de IA inicial OPEN y se documenta en ADR complementario antes de programar adaptador.
