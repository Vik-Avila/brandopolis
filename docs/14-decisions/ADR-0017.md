# ADR-0017 · Brando B1 contextual query path

- Decision: add BRANDO_CONTEXTUAL and its own structured answer contract to the existing Model Gateway.
  Retain the original recommendation task and provider configuration. Use an authorized read projection
  instead of Engine.analyze(), whose persistence and recommendation invalidation are inappropriate for
  contextual questions. Record only separate operational query events in existing telemetry.
- UI: bounded, temporary conversation in a contextual dialog; the existing human workflows remain the
  only strategic write surfaces. References open their recorded content; attention links only navigate.
- Freshness: a B1-specific source fingerprint supplements, without redefining, the recommendation hash.
- Persistence: no new table or migration, no transcript persistence. Durable strategy remains canonical.
- Consequences: cross-reload conversation is intentionally unavailable. Source-ID validation does not
  establish semantic correctness; provider-quality evaluation remains a distinct validation task.
- Release: development outside production only; the Jury Production Freeze is unchanged. No release
  step is authorized by this ADR. Operational contract: [Brando B1](../05-ai/brando-b1.md).
