# ADR-0014 · adaptador IA opcional de piloto

Adaptador Anthropic Messages por HTTPS detrás de ModelGateway, sin SDK en dominio. Activación explícita con ANTHROPIC_API_KEY y ANTHROPIC_MODEL; sin valores por defecto que inventen disponibilidad de cuenta. Salida JSON estructurada según [documentación oficial](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), validación local completa con schema v1 y Evidence Guard. El adaptador transforma sólo restricciones no soportadas por el proveedor; el contrato local no cambia.

Prompt versionado pilot-strategic-v1, contexto tratado como datos no confiables, abort de red y límite de salida. Tokens reales cuando el proveedor los devuelve; costo null hasta una política de precios versionada. No auto-commit, research ni persistencia nueva de prompts. Sin key/model o ante fallo, PILOT informa indisponibilidad y permite decisión humana; no sustituye silenciosamente IA por fixture. DEMO sigue determinista en DB/servidor separado. Cuenta, modelo permitido, presupuesto y consentimiento para procesar datos de testers deben verificarse antes de activar la API real; tests usan respuestas simuladas y no certifican calidad del proveedor.
