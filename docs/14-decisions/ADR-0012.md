# ADR-0012: proveedor DEMO y evaluación conservadora

Se implementa el puerto ModelGateway aceptado con un adaptador determinista DEMO_FIXTURE. No utiliza SDK, red, API key ni inferencia en vivo. El proveedor real permanece OPEN. Las cuatro preguntas prioritarias reciben alternativas didácticas explícitamente fijas, sin atribuir evidencia ni hipótesis no utilizadas. La UI identifica la demostración antes de solicitarla y antes de decidir.

El gateway valida schema, limita caracteres y tiempo, devuelve errores estructurados y registra trazas sin prompts ni contenido estratégico. Tokens y costo son null: no existe consumo de un modelo ni estimación inventada. El timeout no implica cancelación física de un proveedor futuro; un adaptador de red deberá soportar abort y medición real.

El evaluador determinista comprueba referencias autorizadas, existencia de opción recomendada, diferenciación básica y soporte declarado. Las seis dimensiones estratégicas requieren revisión humana; PASS_WITH_CAUTION no certifica calidad. Referencias falsas o inconsistentes impiden guardar una Recommendation utilizable. No cambia Needs Review ni decisiones.

ContextPacket v1 es un snapshot derivado por request: presupuesto explícito de caracteres, decisiones y dependencias críticas obligatorias y lista de omisiones. No se presenta como medición de tokens. Una comprobación transaccional de contextVersion impide publicar una propuesta calculada sobre contexto obsoleto.

Las entidades de contexto se almacenan en tablas independientes con scope compuesto; cada payload representa un solo contrato v1 validado, no un documento agregado de Brand. Captura y revisiones se auditan. No cambia Product Bible, estados ni invariantes.
