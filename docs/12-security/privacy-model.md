# Privacidad

Controlar acceso a datos por Workspace/Brand y User. Consultor multibrand no autoriza transferencia de evidencia, prompts o aprendizajes de Brand A a B. Capability Context personal del User puede sumar práctica a través de Brands sólo como eventos descriptivos sin exponer secretos de clientes. Consentimiento para assessments/piloto; diferenciar export de Brand y de User; proceso de borrado con solicitud, autorización, job auditado, respaldo/retención definidos y confirmación. No usar entradas de clientes para entrenar modelos salvo permiso separado y política explícita. No prometer cumplimiento jurídico específico sin revisión.
