# Product UI Principles

1. **Espacio estratégico, no dashboard genérico.**
2. **Calma ejecutiva.** Senior, claro, premium.
3. **Strategic Glassmorphism with restraint.** Depth supports hierarchy; it does not compete with strategy.
4. **Progressive disclosure.** Essential decision first; depth on demand.
5. **Show why.** Recommendations and Change Impact require rationale.
6. **Show evidence.** Evidence and assumptions are distinct.
7. **Human Authority.** Recommendation ≠ Decision.
8. **State is visible.** Users can understand what is current, what changed and what needs review.
9. **Change is explainable.** Never silently cascade.
10. **History is preserved.** Version semantics are first-class.
11. **No vanity dashboards, gamification or chat-first layout.**

## AI proposes. Human decides.
AI Recommendation uses proposal semantics. A committed Decision uses stronger human-commit semantics with actor/time/version.

## Impacto del cambio
Friendly Spanish pattern: “Tu estrategia ha evolucionado. Algunas decisiones conectadas requieren revisión.” Show what changed, dependency, reason, current state and explicit review action. Never imply Brandopolis already rewrote the downstream decision.

## Language
MVP visible UI defaults to professional Spanish. Canonical brand/category statements such as **The Brand Operating System** may remain in English by deliberate brand choice. Internal code/domain identifiers can remain English.
