# Logo Asset Hierarchy

## Product / UI
Use flat outlined SVG.

## Public hero / campaign
Premium rendered logo is allowed when it improves presentation and does not replace the flat canonical mark.

## Small sizes / favicon
Use the simplified B symbol.

## Never
- baked shadows/glow in normal UI logo;
- particles or transparency artifacts inside B;
- unauthorized color inversion;
- wordmark substitutions;
- font-dependent `<text>` in the official horizontal SVG.
