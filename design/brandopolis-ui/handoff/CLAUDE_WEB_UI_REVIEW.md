# CLAUDE CODE — UI INTEGRATION REVIEW

Review the integrated implementation independently for:
- visual fidelity to canonical screenshots;
- Strategic Glassmorphism restraint;
- no domain/UI state drift;
- Human Authority;
- Requiere revisión semantics;
- no automatic cascade;
- accessibility/focus/keyboard;
- mobile navigation;
- stale-version conflict UX;
- semantic-token usage;
- logo/asset fidelity;
- no replatform;
- no P1/P2 leakage.

Report concrete deviations only. Do not redesign the product.
