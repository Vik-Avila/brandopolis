# Brandopolis brand usage matrix

| Surface | Canonical file |
|---|---|
| Public navbar / product header / email / documentation | `02_runtime/logo/brandopolis-logo-horizontal-color.svg` |
| Public hero / presentations / Open Graph | `03_premium/brandopolis-symbol-premium-2048.webp` or approved horizontal premium PNG |
| Login / request access on light | `02_runtime/logo/brandopolis-logo-horizontal-color.svg` |
| Strategic Workspace sidebar / mobile header | `02_runtime/symbol/brandopolis-symbol-flat-color.svg` |
| Browser favicon | `02_runtime/favicon/favicon.ico` |
| Mobile / PWA app icon | `02_runtime/app-icons/app-icon-192.png`, `app-icon-512.png` |
| Light background | Color horizontal or flat-color symbol |
| Dark / Emerald background | `02_runtime/logo/brandopolis-logo-horizontal-light.svg` or premium symbol |
| Mono print | `04_mono/brandopolis-symbol-mono-charcoal.svg` |
| Small icon 16–32 px | `05_micro/favicon-16.png`, `favicon-32.png` |

Do not recolor by CSS filter or use legacy polygonal symbols. The approved outlined wordmark including its Emerald A accent is retained.
