# Canonical micro usage

The micro mark preserves the canonical master geometry. Small-size legibility is achieved through sizing, safe area and rasterization strategy rather than alternate geometry. Byte-identical SVGs are acceptable. The QA board `06_qa/micro-size-board.png` shows 16, 24, 32, 48, 64, 128 and 256 px. The canonical geometry remains recognizable; no alternate geometry is required at this time. Favicon raster exports use a larger 79% mark safe area than the 67% application icon safe area.
