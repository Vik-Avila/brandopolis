## Skill routing

Skills are procedures and gates, not sources of truth. Canonical copy: `.agents/skills/`; `.claude/skills/` is generated by `pnpm skills:sync` and never edited by hand.

| Change | Skill |
|---|---|
| Behaviour, domain, engine, config, schema or persistence (database gate inside) | brandopolis-feature |
| Frontend presentation, CSS, copy, brand assets | brandopolis-ui |
| AI proposals, prompts, gateway, Brandopolis Intelligence / Brando | brandopolis-brando |
| Auth, sessions, admin, tenancy, endpoints, secrets, logs | brandopolis-security |
| Any new or changed HTTP endpoint / API route | brandopolis-feature + brandopolis-security |
| Review, checks before commit, commit/push/tag/merge/deploy gate | brandopolis-review |
