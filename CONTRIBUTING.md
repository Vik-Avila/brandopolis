# Contribuir

Estados de documentos: canonical, derived, proposed, hypothesis, deprecated. Cambios conceptuales requieren fuente aprobada; cambios técnicos requieren ADR, contrato canónico, schema/config, prueba y actualización de CHANGELOG/SESSION_STATE. No subir datos reales ni secretos a fixtures. Ejecutar `python3 scripts/foundation_check.py`. Si llega el Final Contract Patch independiente, cotejarlo antes de declarar signoff final.
